## Projects

### 👕 [Dry Now](https://github.com/in-river/DryNow)
気象予報とユーザーの物干し環境から、
  
- 今から外に干して大丈夫か  
- 今から干したら何時ごろ乾くか

を推定するFlutterアプリです。

**Tech:** Flutter / Dart / Python / Open-Meteo / SQLite

開発では複数の気象APIを対象に自動データ収集・比較検証を行い、現在はOpen-Meteoを採用しています。  

乾燥時間予測には、VPD・風速・日射・物干し環境などを用いた[乾燥時間予測モデル](https://github.com/in-river/DryNow/blob/main/docs/DRYING_MODEL_V1.md)を実装しています。
